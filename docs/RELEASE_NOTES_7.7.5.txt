R+ 7.7.5 (gasometrías seriadas, y química)
========================================================

Fecha: 2026-07-28

## Resumen

**7.7.5** importa todas las gasometrías del repositorio (empareja la más cercana a labs ≤2 h y deja el resto aparte), une mejor QS/ESC/PFH al consolidar.

## Nuevo / mejorado

- **Gasometrías del repo** — Trae todas las tomas; junta solo la gaso más cercana a labs dentro de ≤2 h; un conjunto nunca absorbe una segunda gasometría (tampoco si ya trae GASES).
- **Química al consolidar** — QS/ESC/PFHs/Lipasa se fusionan por campos (p. ej. CPK no se pierde); más alias de CPK/CK en el parser.
- **Consolidar UI** — Tras fusionar, el historial selecciona el conjunto keeper y refresca tendencias/estudios.

## Instalación

Descarga desde: https://github.com/mausalas99/r-mas/releases/tag/v7.7.5

- Mac: `R+-7.7.5-arm64.dmg`, `R+-7.7.5-x64.dmg` (y zip para auto-update).
- Windows: `R+-7.7.5-x64.exe`.

Tras el build local: `npm run build:mac` / `npm run build:win` (incluye write-release-yml.js).
