R+ 8.1.3 (instrumento + SOME Nube + censo)
==============================================

Fecha: 2026-08-14

## Resumen

**8.1.3** afina el instrumento (botones ink, overlays desde el control, chips neutros), manda el SOME crudo por Nube para que cada Mac reparsee, y deja recorrer el censo con ↑/↓. Unirse a un equipo ya no borra asignaciones que el compañero aún no había bajado.

## Nuevo / mejorado

### Instrumento

- **Botones** — Primarios ink (claro) / azul clínico (oscuro); radio 8px; sin pastillas 999px. Se quita la cápsula **+1 día** junto a Importar SOME.
- **Overlays** — Abren desde el botón que los disparó, sin rebote. Tras un flick, el sheet cede (rubberband) en vez de pegarse al borde.
- **Chips / shell** — Acento suave ink-neutral (sin ocre). El pegado SOME asienta el panel.

### Laboratorio / Nube

- **SOME en Nube** — El turno envía `sourceText`; cada Mac reparsea localmente si `resLabs` viene vacío. No se pisa un set que ya tiene filas.
- **Historial** — Navegación por día más estable (prune de duplicados exactos; settle al pegar).

### Censo / Pase

- **↑ / ↓** — Recorre el censo visible (fija → activos → archivo). No aplica al escribir, ni con un diálogo/menú abierto.
- **Toque** — En iPad/puntero, soltar sobre la tarjeta selecciona el paciente (el `:active` ya no se come el click).
- **Pase** — El glance de Resumen se invalida cuando cambian pendientes o eventualidades.

### Nube / Worker

- **Asignaciones** — Un push de join/perfil une filas de `clinicalOps` (no last-write-wins a ciegas): no se pierden `patient_team_assignment` que el emisor aún no había bajado.
- **Cupo** — Más margen de mutaciones por sala y minuto (guardia con varias Macs + labs).
- **CPU Worker** — Límite 30 s (Paid) para el snapshot LWW de sala.

### macOS

- **Firma** — El `.dmg` se firma con **Developer ID Application** y se notariza cuando el publish tiene `APPLE_ID` / `APPLE_TEAM_ID` / contraseña de app. En una Mac limpia no debería hacer falta clic derecho → Abrir.

## Instalación

El bloque **Descargar** al inicio de las notas en GitHub tiene los tres instaladores con nombres legibles.

- Mac Apple Silicon (M1–M4): `R+-8.1.3-Mac-Apple-Silicon.dmg`
- Mac Intel: `R+-8.1.3-Mac-Intel.dmg`
- Windows: `R+-8.1.3-Windows.exe`

Instala **8.1.3 en todas las Macs** del turno. **Despliega el Worker** (LWW clinicalOps + cupo); el de 8.1.0 no basta.

Tras el build local: `npm run build:mac` / `npm run build:win` (incluye write-release-yml.js).

## Notas

- Peers en **8.1.2** siguen en el mismo turno; conviene actualizar todas las Macs el mismo día (SOME `sourceText` + Worker nuevo).
- **Sin wipe al actualizar** — SQLCipher y `userData` persisten; schema **v23** no cambia.
- **Recuérdame** guarda token en el dispositivo; no usar en Macs compartidas.
