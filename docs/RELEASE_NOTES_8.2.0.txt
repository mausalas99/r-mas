R+ 8.2.0 (estable — release 8.2.0)
======================================

Fecha: 2026-08-24

## Resumen

Llave de rescate para salas de Nube, animaciones al agregar/quitar filas, y correcciones de sincronización.

## Nuevo / mejorado

- **Llave de rescate de sala (admin):** si se pierde el código de la sala y ningún dispositivo tiene la llave en caché, el admin puede recuperar el acceso con su propia llave. Se guarda una copia extra de la llave de la sala, cifrada solo para el admin.
- **Rotación de llave de sala:** al rotar el código de una sala, la llave cifrada se puede reemplazar sin perder acceso a los datos ya guardados.
- **Animaciones en listas (censo, pendientes):** las filas nuevas aparecen con transición y las que se quitan se desvanecen, en vez de aparecer/desaparecer de golpe.
- **Corrección de fusión de pacientes:** al comparar signos vitales de dos registros para decidir cuál es más reciente, ahora se usa la hora real de guardado en vez de la hora clínica editable, evitando empates que perdían datos.
- **Panel de guardia por celular (Interno) desactivado temporalmente:** mientras se migra a cifrado de extremo a extremo, el panel y el registro de signos vitales por celular responden "temporalmente desactivado" en vez de fallar.

## Instalación

El bloque **Descargar** al inicio de las notas en GitHub tiene los tres instaladores con nombres legibles.

- Mac Apple Silicon (M1–M4): `R+-8.2.0-Mac-Apple-Silicon.dmg`
- Mac Intel: `R+-8.2.0-Mac-Intel.dmg`
- Windows: `R+-8.2.0-Windows.exe`

Tras el build local: `npm run build:mac` / `npm run build:win` (incluye write-release-yml.js).
