## C — Missing CORS on JSON routes

`cloud/update-worker/src/index.mjs:41` — the `min-version.json` / `stable-versions.json` routes only set `Content-Type` and `Cache-Control`. These are fetched from the renderer (`app://rplus` origin), which Chromium will block without CORS. Add `'Access-Control-Allow-Origin': '*'` to those two routes' response headers. (The yml routes are fetched from the main process and don't need this.)

Add a test in `cloud/update-worker/src/index.test.mjs`: JSON route response carries `Access-Control-Allow-Origin: *`.
