R+ 7.7.9 (labs alterados sin rangos + historial sin clones)
==========================================================

Fecha: 2026-07-31

## Resumen

**7.7.9** marca valores fuera de rango aunque el SOME no traiga «Valor de Referencia», evita clonar el mismo set al reimportar (misma hora / mismos GASES), y afina Actualizar labs.

## Nuevo / mejorado

- **Alterados sin rangos** — Si el reporte no trae referencia, R+ aplica rangos de estudios previos del mismo paciente; si no hay, estándares (p. ej. pH 7.35–7.45, Glu 70–100, Na 136–145).
- **Todos los paneles** — BH, QS, ESC, PFHs, lipasa, paneles extendidos y gasometría (no solo gases).
- **Sin clones en historial** — Misma fecha+hora: no crea Labs (1)…(8); paneles nuevos se anexan al set. Mismos GASES se filtran; gasos seriados distintos siguen aparte.
- **Actualizar labs** — Cola anclada al pie del sidebar; lista de pacientes más limpia; **Todos / Solo activo / Ninguno**; toolbar Laboratorio con Limpiar al final.

## Instalación

Descarga desde: https://github.com/mausalas99/r-mas/releases/tag/v7.7.9

- Mac: `R+-7.7.9-arm64.dmg`, `R+-7.7.9-x64.dmg` (y zip para auto-update).
- Windows: `R+-7.7.9-x64.exe`.

Tras el build local: `npm run build:mac` / `npm run build:win` (incluye write-release-yml.js).
