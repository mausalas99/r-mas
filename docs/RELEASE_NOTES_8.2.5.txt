R+ 8.2.5 (estable — release 8.2.5)
======================================

Fecha: 2026-08-29

## Resumen

Permite borrar un cultivo suelto del historial, corrige lotes de sync de labs que se quedaban atascados en Nube, y termina de unificar el texto de la app a tuteo.

## Nuevo / mejorado

- **Borrar un cultivo del historial:** cada fila de cultivo tiene ahora un botón para quitar solo ese set de labs, sin tener que reimportar todo el historial para corregir una entrada duplicada o mal cargada.
- **Menos lotes atascados en Nube:** el envío de labs pendientes armaba un lote por paciente sin límite de tamaño; un paciente con muchos labs pendientes podía generar un lote demasiado grande y quedar atorado como "lote pesado". Ahora los lotes tienen un tope y ya no se atascan.
- **Texto en tuteo:** las últimas frases en voseo (exportá, asignás, elegí) ya usan tú, igual que el resto de la app.

## Instalación

El bloque **Descargar** al inicio de las notas en GitHub tiene los tres instaladores con nombres legibles.

- Mac Apple Silicon (M1–M4): `R+-8.2.5-Mac-Apple-Silicon.dmg`
- Mac Intel: `R+-8.2.5-Mac-Intel.dmg`
- Windows: `R+-8.2.5-Windows.exe`

Tras el build local: `npm run build:mac` / `npm run build:win` (incluye write-release-yml.js).
