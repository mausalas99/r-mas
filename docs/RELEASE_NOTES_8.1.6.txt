R+ 8.1.6 (estable — release 8.1.6)
======================================

Fecha: 2026-08-20

## Resumen

Corrige varios bugs de parsing de labs (EGO, cultivos, egresos) y para un bug donde Estado actual podía mostrar signos vitales de otro paciente.

## Nuevo / mejorado

- **Estado actual — signos vitales ya no se cruzan de paciente:** la sincronización en segundo plano podía escribir los vitales de un paciente en la ficha de otro. Ya no pasa.
- **Cultivos — ya no se duplican al actualizar:** "Actualizar" podía crear una fila repetida del mismo cultivo en vez de reemplazar la existente. Ahora se identifica el mismo aislamiento por microorganismo + cuenta y se queda con el reporte más completo.
- **EGO — ya no se apila un campo por línea:** un resultado de EGO con varios campos por línea se leía mal y quedaba un campo por renglón.
- **Egresos — "E" a media palabra ya no se confunde con Egreso:** el detector de egresos disparaba con una "E" suelta dentro de otra palabra.
- **Censo — ya no se duplican estudios repetidos:** un mismo estudio de laboratorio podía aparecer dos veces en el censo; también se quitó "BH extendido" de la lista.
- **Tendencias — la búsqueda de un estudio ya no pierde secciones:** un fragmento de texto viejo podía hacer que la vista de tendencias mostrara menos secciones de las que hay.

## Instalación

El bloque **Descargar** al inicio de las notas en GitHub tiene los tres instaladores con nombres legibles.

- Mac Apple Silicon (M1–M4): `R+-8.1.6-Mac-Apple-Silicon.dmg`
- Mac Intel: `R+-8.1.6-Mac-Intel.dmg`
- Windows: `R+-8.1.6-Windows.exe`

Tras el build local: `npm run build:mac` / `npm run build:win` (incluye write-release-yml.js).
