R+ 8.1.5 (estable — release 8.1.5)
======================================

Fecha: 2026-08-16

## Resumen

Atajo nuevo para copiar labs del equipo, sincronización en Nube más resistente a un item atascado, y ajustes de tamaño en el dashboard de paciente.

## Nuevo / mejorado

- **Atajo ⌘⇧C — copiar labs del equipo:** copia los labs de hoy de los pacientes fijados con un atajo de teclado.
- **Nube — un item atascado ya no detiene la cola:** si un cambio falla al enviarse, los demás cambios pendientes se siguen enviando; antes toda la cola se congelaba en el primer error.
- **Nube — límite de tamaño de labs más seguro:** se bajó el máximo de un op de labs para que siempre quepa en un envío; antes un op grande podía quedar atascado para siempre en la cola de salida.
- **Dashboard de paciente:** la tarjeta de signos vitales se ve más compacta cuando no hay datos, y el panel hace scroll si el contenido no cabe.
- **Lista de pacientes:** el orden de "siguiente paciente" se actualiza al arrastrar y reordenar en la barra lateral.

## Instalación

El bloque **Descargar** al inicio de las notas en GitHub tiene los tres instaladores con nombres legibles.

- Mac Apple Silicon (M1–M4): `R+-8.1.5-Mac-Apple-Silicon.dmg`
- Mac Intel: `R+-8.1.5-Mac-Intel.dmg`
- Windows: `R+-8.1.5-Windows.exe`

Tras el build local: `npm run build:mac` / `npm run build:win` (incluye write-release-yml.js).
