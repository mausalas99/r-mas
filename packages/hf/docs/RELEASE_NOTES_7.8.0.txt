R+ 7.8.0 (labs sin refs + debt baseline)
=======================================

Fecha: 2026-08-01

## Resumen

**7.8.0** marca alterados en QS/ESC/PFH/BH aunque SOME omita «Valor de Referencia» (rangos previos del paciente o estándares). Baja deuda estructural (complejidad/length → 0) y refresca el baseline de métricas.

## Nuevo / mejorado

- **Alterados sin rangos** — Química/PFH/ESC sin columna de referencia usan rangos de estudios previos; si no hay, estándares (p. ej. Cl 96–106, LDH 120–250).
- **Historial** — Reproceso completo del SOME al mantener historial; match de expediente con dígito (`1087426` ↔ `1087426-2`); no inventa PCT fantasma.
- **Debt** — Complejidad y overage de longitud en 0; baseline `totalScore=0`. Shell modularizado (`app-shell-*`) con imports diferidos.

## Instalación

Descarga desde: https://github.com/mausalas99/r-mas/releases/tag/v7.8.0

- Mac: `R+-7.8.0-arm64.dmg`, `R+-7.8.0-x64.dmg` (y zip para auto-update).
- Windows: `R+-7.8.0-x64.exe`.

Tras el build local: `npm run build:mac` / `npm run build:win` (incluye write-release-yml.js).
