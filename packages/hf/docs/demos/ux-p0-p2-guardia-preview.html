Cada escena compara hoy vs propuesta. La magia del producto es la integración Laboratorio + Estado actual / datos del paciente → Nota de evolución (Interconsulta) → Word, más predeterminados de indicaciones a un clic. Strip y transfer son soporte de turno, no el spine.
